# NetSentry

## Advanced Network Discovery and Security Risk Assessment Framework

NetSentry is a cybersecurity-focused network scanning and security assessment framework designed to discover authorized network hosts, identify exposed services, analyze security risks, and provide structured security insights.

## Project Status

🚧 Under Development

## Current Features

- Host discovery using Nmap
- Python-based network scanning architecture
- Basic authorized network reconnaissance

## Planned Features

- TCP port scanning
- Service and version detection
- Operating system detection
- Device fingerprinting
- Security risk scoring
- Vulnerability and CVE mapping
- Scan history
- Network topology visualization
- Security dashboard
- Network change detection
- Report generation
- ML-based risk classification

## Technology Stack

- Python
- Nmap
- Flask
- HTML
- CSS
- JavaScript
- Bootstrap
- SQLite / PostgreSQL
- Scikit-learn
- Docker

## Disclaimer

NetSentry is intended for authorized security testing, defensive security research, and educational purposes. Only scan systems and networks for which you have explicit permission.
